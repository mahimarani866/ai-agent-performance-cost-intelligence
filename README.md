# AI Agent Performance & Cost Intelligence Dashboard

## Project Overview

An advanced Power BI analytics project designed to analyze AI agent performance, model efficiency, execution costs, and operational reliability.

The dashboard aims to help users compare AI models, understand task outcomes, monitor execution costs, and identify opportunities for optimization.

## Objectives

- Analyze AI agent runs across different roles and models.
- Compare model performance using available evaluation scores.
- Monitor model and data-related costs.
- Analyze task categories and execution times.
- Evaluate task completion and reliability.
- Compare models based on performance, cost, and speed.

## Tools & Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX
- CSV datasets
- Data visualization and data modeling

## Dataset

The project uses two datasets:

1. Agent Runs by Role and Model
2. Agent Model Tests

The detailed model-test dataset contains 210 records.
